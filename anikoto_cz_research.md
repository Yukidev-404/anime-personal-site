## 1. Website Overview

AniKoto (anikoto.cz) is a free anime streaming platform offering:

- **Massive anime catalog** spanning numerous genres from classic to latest releases
- **English subtitles or dubbed audio** options
- **Multiple optimized servers** for best performance based on user location
- **High-resolution video quality** with adjustable quality levels
- **Fast updates** - new episodes and content added frequently
- **Clean, intuitive interface** designed for easy navigation
- **Multi-device support** - works on desktops, tablets, and mobile phones (including older browsers)

## 4. Technical Observations

### 4.1 Domain and Hosting
- Primary domain: **anikoto.cz**
- Alternative/bookmark domain: **anikoto.site** (mentioned for domain updates)
- Uses CDN services: **cdn.anipixcdn.co** for thumbnails/background images
- TMDB (The Movie Database) poster images used for some anime

### 4.2 Content Delivery
- Thumbnail images from **cdn.anipixcdn.co**
- Banner/background images from **cdn.anipixcdn.co**
- Some anime use **image.tmdb.org** for banners
- **Anilist.co** referenced for anime metadata (e.g., `s4.anilist.co/file/anilistcdn/media/`)

### 4.3 Interface Elements
- Dark theme design
- Language toggle (EN JP)
- Quality selection (EN JP language options)
- Filter controls
- Quick access toolbar with: Watch2gether, Community, Schedule, Random
